# 뚝딱! 한글

블록이 **뚝** 떨어지고, 연필로 **딱** 받으면, 글자가 **뚝딱** 만들어진다.

2026 한글날 코딩 프로젝트 · 1번 주제 "한글 익히기" 데모.

떨어지는 자음·모음 블록을 **첫소리 → 가운뎃소리 → 끝소리** 순서로 받아 글자를 조립한다.
ㄱ → 가 → 강 처럼 받을 때마다 글자가 조립되는 모습이 화면에 보인다.

## 실행

`index.html` 을 브라우저로 연다. 설치할 것도 없고 인터넷도 필요 없다.

| 조작 | 키 |
|---|---|
| 이동 | ← → (또는 A D), 게임판 누르기·끌기, 모바일 ◀ ▶ 버튼 |
| 일시정지 | P / Esc |
| 시작·다음 | Enter / Space |

## 학습 설계

| 단계 | 내용 | 도움 |
|---|---|---|
| 1단계 | 받침 없는 글자 (나무, 바다…) | 다음 자모 표시 + 받을 블록 반짝임 + 방향 화살표 |
| 2단계 | 받침 있는 글자 (곰, 꽃…) | 다음 자모 표시 + 방향 화살표 |
| 3단계 | 한글 달인 (세종, 호랑이…) | 도움 없음. `? + ? + ?` 를 스스로 풀어야 한다 |

- 자음은 파랑, 모음은 주황으로 색을 나눈다.
- 방향 화살표: 받아야 할 블록이 있는 쪽으로 받침대 옆에 `›››` 가 뜨고(칸 수만큼 최대 3개), 그 칸이 은은하게 밝아진다. 맞는 칸에 서면 초록 `∨` 로 바뀐다. `words.js` 의 `guide` 로 단계마다 켜고 끈다.
- 방해 블록은 헷갈리기 쉬운 짝(ㄱ/ㅋ, ㅏ/ㅓ, ㅗ/ㅜ)과 단어 안의 다른 자모(순서 헷갈리기)에서 고른다.
- 틀리면 **제자 원리**로 설명한다. 예: "ㅋ은 ㄱ에 획을 더한 글자예요", "ㄲ은 ㄱ을 두 번 쓴 된소리예요".
- 첫소리 ㅇ 은 소리가 없다는 것처럼, 헷갈리는 규칙은 그 순간에 알려 준다.
- 완성한 글자와 단어는 브라우저 음성(ko-KR)으로 읽어 준다.

## 파일

- `hangul.js` — 한글 음절 조합·분해 (유니코드 0xAC00 공식)
- `words.js` — 단계와 단어 목록. 단어를 늘리려면 여기에 `['단어', '이모지']` 를 추가한다. 겹받침(ㄳ·ㄺ 등)은 넣지 않는다
- `game.js` — 게임 루프·판정·화면
- `index.html?debug` 로 열면 `window.__hg` 로 상태를 볼 수 있다 (테스트용)
